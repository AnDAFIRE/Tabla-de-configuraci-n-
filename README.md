# 🧪 Actividad: Matriz de Configuración Electrónica

## 📘 Descripción
Este proyecto muestra la **configuración electrónica** de los niveles de energía de los átomos mediante una **matriz bidimensional** en JavaScript.  
El programa imprime en la **consola del navegador** una tabla organizada que representa los orbitales atómicos (s, p, d, f) según los niveles principales (1 a 8).

---

## ⚙️ Archivos del proyecto

### 🧩 `index.html`
Archivo principal que carga el script JavaScript y muestra un mensaje indicando cómo visualizar el resultado.

### ⚙️ `script.js`
Contiene la lógica del programa.  
Define la matriz `configuracionElectronica` y recorre sus filas y columnas para imprimir la estructura electrónica ordenada en la consola.

---

1. Clona o descarga este repositorio en tu computador.

3. Presiona **Ctrl + Shift + I** (Windows/Linux) o **Cmd + Option + I** (Mac) para abrir las **herramientas de desarrollo**.
